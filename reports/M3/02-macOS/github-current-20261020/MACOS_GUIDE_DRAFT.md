# Mac installation and first-use guide — incomplete draft

Actual 1920 x 1080 PNGs from the Apple silicon GitHub Mac runner, using the latest customer ZIP. These are original screenshots.

**Installation progress/completion and consumer Gatekeeper approval are not illustrated or verified. This is not a complete customer installation guide.** The launch/application screenshots follow a separately logged command-line CI installation.

The real macOS administrator-password prompt was captured in `01-Apple-silicon/installation/006-installer-step-2.png`. It displays the generic CI account name and is excluded from the customer illustration sequence. On your own Mac, an installation authentication prompt uses your Mac account; it is separate from Gatekeeper. No credentials were entered or security settings changed.
